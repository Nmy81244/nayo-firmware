# nayo-firmware

## Description

Simple firmware for the nayo board, a simple 4 key Sayo Device style macropad featuring the AT32F405 microcontroller.

## Features

- 8kHz polling rate (TBI)
- Support for up to four linear magnetic switches
- Support for up to 10 addressable RGB LEDs (TBI)
- Monochromatic I2C display support (TBI)
- Rotary encoder support (TBI)
- Rapid-trigger support (TBI)
- Macro customization support (TBI)
- Custom animation support (TBI)
- OpenRGB support (TBI)
- Quick illumination presets (TBI)
- Quick layout presets (TBI)
- Code execution (TBI)
- Graphical menu (TBI)

## Hardware
- WeAct AT32F405CCT6
- MT9105ET
- I2C SSD1306
- WS2812B
- EC11 Encoder
